# Card Learning Demo 总览

## 1. Demo 定位

Card Learning Demo 是 AI-Journey-Land 的第四个 Demo，定位为**全栈数据库学习项目**。

它不是一个简单的"卡片应用"，而是一个**渐进式知识管理系统**——用"一张知识卡片的一生"串联全部数据库技术栈：

```text
创建 Card → PostgreSQL 持久化 → Redis 缓存 → MongoDB 行为日志 → Elasticsearch 搜索 → IndexedDB 离线 → AI 能力
```

每个阶段只引入一个新技术，逐步深入，不急于一次全做。

## 2. v0.1 MVP

当前阶段（v0.1）已完成：

- PostgreSQL 17 数据库（Docker Compose 启动）
- Prisma ORM 集成（type-safe 数据访问）
- NestJS CardsModule（CRUD + 标签 + 学习记录）
- 4 张数据表：`cards` / `tags` / `card_tags` / `learning_records`

## 3. 技术栈

| 层     | 技术           | 说明                               |
| ------ | -------------- | ---------------------------------- |
| 数据库 | PostgreSQL 17  | 主业务数据库，支持 JSONB、全文搜索 |
| ORM    | Prisma 7       | 类型安全、自动 migration           |
| 后端   | NestJS         | Module/Controller/Service 三层架构 |
| 前端   | Nuxt 4         | 复用现有组件体系                   |
| 部署   | Docker Compose | 一键启动 PG 实例                   |

## 4. 数据模型

```
cards ──┬── card_tags ──┬── tags
        │
        └── learning_records
```

- `cards`：卡片主表（title / content / category / difficulty / status）
- `tags`：标签表（name UNIQUE）
- `card_tags`：多对多关联表（card_id + tag_id 联合主键）
- `learning_records`：学习记录（action / note）

## 5. API 端点

| 方法   | 路径                   | 说明                      |
| ------ | ---------------------- | ------------------------- |
| GET    | /api/cards             | 列表（含 tags）           |
| GET    | /api/cards/:id         | 详情（含 tags + records） |
| POST   | /api/cards             | 创建                      |
| PATCH  | /api/cards/:id         | 更新                      |
| DELETE | /api/cards/:id         | 删除                      |
| POST   | /api/cards/:id/records | 添加学习记录              |
| GET    | /api/cards/:id/records | 学习记录列表              |

## 6. 核心文件

| 文件                                     | 说明                          |
| ---------------------------------------- | ----------------------------- |
