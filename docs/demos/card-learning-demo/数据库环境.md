# Card Learning Demo 数据库环境

## 1. Docker 启动 PostgreSQL

### 前提条件

- Docker Desktop 已安装并运行
- 端口 15432 未被占用（如被占用，修改 `docker-compose.yml` 中 `ports` 配置）

### 启动命令

```bash
# 在项目根目录执行
docker compose up -d postgres
```

首次启动会从 Docker Hub 拉取 `postgres:17-alpine` 镜像（约 120MB）。

### 查看状态

```bash
docker compose ps
# 应显示 ai-journey-pg 状态为 Up (healthy)

docker compose logs postgres
# 查看 PostgreSQL 启动日志
```

### 停止/重启

```bash
docker compose stop postgres    # 停止（保留数据）
docker compose start postgres   # 启动
docker compose down -v postgres # 停止并删除数据卷（⚠️ 数据丢失）
```

## 2. 连接信息

| 参数 | 值 |
|------|-----|
| Host | `localhost` |
| Port | `15432`（对外映射端口） |
| 容器端口 | `5432` |
| User | `journey` |
| Password | `journey123` |
| Database | `ai_journey_lab` |
| Schema | `public` |

### 完整连接 URL

```
postgresql://journey:journey123@localhost:15432/ai_journey_lab?schema=public
```

## 3. 连接工具推荐

### psql（命令行）

```bash
# 通过 docker exec 进入容器
docker compose exec postgres psql -U journey -d ai_journey_lab

# 或本地安装 psql 后连接
psql postgresql://journey:journey123@localhost:15432/ai_journey_lab
```

常用命令：
```sql
\dt          -- 查看所有表
\d cards     -- 查看 cards 表结构
SELECT * FROM cards;  -- 查询所有卡片
\q           -- 退出
```

### GUI 工具

- **DBeaver**（免费）：支持 PostgreSQL / MySQL / MongoDB / Redis 等多数据源
- **TablePlus**（macOS）：简洁快速的数据库管理工具
- **pgAdmin**（Web）：PostgreSQL 官方管理工具

## 4. Prisma 数据库操作

### 初始化（已执行）

```bash
cd apps/api
npx prisma migrate dev --name init
```

### 日常开发

```bash
cd apps/api

# 修改 schema.prisma 后生成迁移
npx prisma migrate dev --name add_xxx

# 仅生成 Prisma Client（不创建迁移）
npx prisma generate

# 查看数据库（Prisma Studio）
npx prisma studio
```

### 重置数据库

```bash
cd apps/api
npx prisma migrate reset    # 删除所有数据并重新建表
```

## 6. Docker Compose 配置说明

```yaml
# docker-compose.yml
services:
  postgres:
    image: postgres:17-alpine       # 轻量 Alpine 镜像
    container_name: ai-journey-pg   # 固定容器名
    restart: unless-stopped         # 异常停止后自动重启
    ports:
      - '15432:5432'                # 宿主机端口:容器端口
    environment:
      POSTGRES_USER: journey
      POSTGRES_PASSWORD: journey123
      POSTGRES_DB: ai_journey_lab
    volumes:
      - pgdata:/var/lib/postgresql/data  # 数据持久化

volumes:
  pgdata:                           # Docker 管理的命名卷
```

- `volumes: pgdata` 确保容器删除后数据仍在
- `restart: unless-stopped` 保证系统重启后自动恢复
- Alpine 镜像体积小，启动快
